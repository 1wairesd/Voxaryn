# Project origins and attribution

Voxaryn starts from the open-source **Horizon** project by Ludovic and other contributors:
https://github.com/ludovic111/horizon

The initial code was obtained through a GitHub fork at `1wairesd/mc-rust`. The repository preserves the original Git commit history and authorship. The starting codebase is not an independent implementation written from scratch by the Voxaryn project.

Horizon is distributed under the MIT license. The original LICENSE file and copyright notices are retained. See Git history for prior authors and changes.

Voxaryn's region-based multithreading is a proposed direction, not a claim about existing functionality. This project is not affiliated with the Horizon maintainers, Mojang, or Microsoft.
